# 验证、交付与维护

## 按证据定位

记录用户症状、准确页面／关卡、输入动作、构建指纹、环境版本、最新日志和截图，区别译义错误、映射错误、排版裁切、错资源、漏加载、内存／封包故障、模拟器兼容。先选能排除一个假说的最小对照，不盲调分辨率、帧率、驱动或重下载。

同配置测试原版与候选，再逐一改变字体、文本、贴图、影片、更新／DLC。原版也崩则不能直接怪汉化；原版正常也不能直接断言一定是译文字节，而应缩小改动集。错误日志是线索，不是因果证明。

路径检查涵盖实际启动入口、大小写、分隔符和虚拟文件系统；宿主系统看得见文件不保证游戏能按请求路径读到。只改一个疑似文件无效不能证明整类假说成立或不成立。

## 五层证据

| 层次 | 能支持什么 | 不能支持什么 |
|---|---|---|
| 清单与解析 | 已解析范围、待查资源、稳定 ID | 没有任何遗漏 |
| 语言与显示静态检查 | 控制码、术语、字形、UV／排版候选 | 游戏已读取正确资源 |
| 写回／往返 | 指针和容器可重建、修改范围受控 | 程序不崩、内存足够 |
| 运行 | 某构建在某平台的指定场景通过 | 全版本全平台全关卡通过 |
| 安装与发布 | 接收者能重建目标，远端资产一致 | 所有剧情译义准确 |

每条测试绑定构建哈希；构建变化后按依赖分析使相关测试失效，不能拿旧测试替新构建背书。源码分析、自动检查、用户确认和直接观察分别标注。

## 运行矩阵

按修改影响选择：冷启动、加载复制的游戏内存档、主菜单／设置／按键帮助、最长文字和动态变量、改名、商店／装备、剧情分支、战斗、结算、存读档、返回菜单、退出重进。字体／内存改动覆盖高驻留场景及重复进入；字幕覆盖首次／再次、跳过、结束转场；更新／DLC 测到进入内容、完成结算、保存再读取。

旧即时存档可能携带旧程序和字体，验证新二进制先冷启动再读游戏内存档。使用测试存档副本。玩家正在游玩时先完成离线工作，重启前保护未保存进度；已有明确退出授权无需重复询问。

测试矩阵未执行的格子写未测。工具无法控制窗口／按键时不要谎称看到目标页面，可交付明确复现路径请玩家验证。验证报告写观察到的事实，例如“当前已在测试战斗”不能写成“亲自完成了进入、战斗、退出全流程”。

## 构建与安装

固定来源指纹、工具版本、译文修订、字体和输出指纹。保存变更清单及最后一个可用回退点；生成式中间文件按重建成本保留，不无限积累完整镜像。删除旧备份先确认用户范围及恢复策略。

差分应区分原版首次安装和旧汉化升级；支持每个基线哈希，不用模糊文件名判断版本。安装器应预检全部输入、目标版本、空间和写入权限；拒绝未知／混合版本，避免半安装。写临时输出、验证、再提交；失败清理不完整输出。原地多文件安装需持久事务日志和可验证回退，恢复不能覆盖用户之后的修改。

测试成功路径之外的关键失败：错误基线、缺少分卷、已有目标、路径含中文／空格、只读、空间不足、意外中断、重复安装、还原。备份要校验；不能只用存在文件名证明恢复可用。大型文件流式处理，避免把整套游戏载入 RAM。

## 发布体验

跨平台安装器把“同一游戏数据可用”和“启动工具可执行”分开验证。附带 Python/其他运行时时，按 Windows 架构、macOS Intel/Apple 芯片或已验证通用二进制确认实际可运行性，保留依赖许可、可执行权限及离线启动说明；只有脚本就不要写成免依赖 APP。Windows/Intel Mac 未执行过应如实列出，不能由 Apple 芯片 Mac 上测试代替。

正式/预发布标签遵循用户已授权的发布决定，不能把技能中的候选默认值当成额外审批要求；真实未测范围继续保留。PS3 ISO 与 CFW/HEN 的专门边界见 [PS3 封装与实机](ps3-packaging.md)。

用户面对的入口保持清楚：当前发行、先读说明、对应平台启动工具、支持版本、回退方式。开发临时文件另放。说明在压缩包里面，不依赖聊天记录；整合版、原版差分、旧版升级不能互相冒充。不要夹带个人存档、BIOS、账户文件或未审查的其他工具；素材分发按实际范围与许可处理。

有发布授权再上传。发布前在干净目录从包内说明完成一次安装，核对输出指纹与待测构建；测过哪种操作系统如实标注。发布标候选／测试版并不是免除已知致命缺陷；若用户明确要求带已知限制发布，应醒目标出影响、受影响条件及可用回退。

上传后重新读取远端 release 状态、资产名、大小与可用哈希，必要时下载复核。请求报错可能已经成功，先读状态再重试，不无限追加重复资产。ASCII 资产文件名加中文说明可减少工具兼容问题，但不是平台硬性要求。平台附件限制查当前文档，不把一次经验写成永久数值。

## 收到新问题

缺陷单包含原文 ID／页面、重现步骤、预期／实际、版本与哈希、证据、影响级别和回归测试。问题修在源译文／源资产／生成器，重新构建；不要只手修发布包。归因确认后增加真正能捕获故障的检查，更新适配器支持范围。
