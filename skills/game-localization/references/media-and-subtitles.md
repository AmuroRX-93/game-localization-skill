# 影音、字幕与媒体工具链

先区分软字幕、游戏独立屏幕字幕层与画面写死的硬字幕，再决定处理方式。

## 1. 载体识别与原文核对

- 区分原生事件字幕、实时引擎字幕、视频烧录硬字幕、无字幕音轨与外部观看 MP4；导出观看合集与可回装游戏影片是不同交付。
- 先确认影片在游戏中的呈现方式（全屏、人物窗口裁切、纹理映射、遮罩与 HUD 覆盖）。若画面硬字幕因人物窗口/UV 裁切不可见，应改用独立屏幕字幕层。
- 优先查找游戏脚本原文与说话人/事件 ID，再对照原声；ASR 仅作候选，专名、番号、数字、否定与同音词必须人工复听核对。多声道先听辨语音声道，识别为空不直接断言无对白。每段记录时长、帧数、音轨、对白判定、来源与审校状态。

## 2. 原生与实时字幕时序及排版

- **触发与时序**：检查文本、触发事件、窗口状态、显示区间、清屏、切镜、跳过与重播；同时测试冷缓存首次播放与二次平稳播放，防止卡顿引发漏句。
- **程序叠加字幕**：绑定真实播放资源、播放实例与通道状态，不靠关卡启动后的固定延时模拟全部通讯。需延长到影片结束后的字幕应独立保存剩余区间与所属播放实例，明确新对白、重播、跳过与退出时的清理规则；使用备用时钟前先校准暂停行为与单位换算。
- **实时字幕排版**：共用一致的屏幕锚点、字体度量与 HUD 安全区，按真实渲染字宽逐行居中；多通道并发时限制同时显示的总行数，避免叠加超出安全区。长句按语义无丢字分页，验证首尾页、抢占、暂停与续播。

## 3. 影片回装边界

- 记录原容器、编码 profile/level、分辨率、timebase/帧率、帧数、GOP、音频编码与声道、码率峰值、流 ID、交织、索引、对齐与专用元数据。
- 先用短代表片验证完整封装链：首帧、全片、跳过、结尾 loading、进入战斗、返回菜单。桌面播放器能解码不代表游戏解码器可稳定播放；出现黑屏时对照原片、未改字幕的重封装片与修改片定位根因。

## 4. 可选媒体工具（`scripts/media_toolkit.py`）

Python 3.9+，不含模型权重、FFmpeg 或商业字体，不自动下载或调用云端服务，所有写入均输出新候选且拒绝覆盖。先运行：

```sh
python3 scripts/media_toolkit.py doctor
```

可用全局 `--ffmpeg` / `--ffprobe` 指定二进制路径。

| 命令 | 用途 | 外部依赖与限制 |
|---|---|---|
| `probe` | 检查流/声道/时间基 | `ffprobe` |
| `extract` | 提取 16kHz 单声道 WAV（`--audio` / `--channel`） | `ffmpeg`；仅用于识别，不替代发行音轨；需核对非零 PTS 偏移 |
| `transcribe` | 本地 ASR 生成原文候选（`--model-dir` / `--language` / `--offset`） | `faster-whisper` + 完整本地 CTranslate2 模型目录（CPU/int8）；`text` 初始为空、`reviewed` 为 `false` |
| `check` | 检查空字幕、重叠、越界、未审与阅读速度（`--max-cps` / `--max-line`） | 标准库；不判断译义准确性 |
| `export` | 导出 SRT/ASS（`--format srt|ass`） | 标准库；ASS 仅导出纯文本样式，拒绝 `{`/`}`/`\` |
| `burn-preview` | 烧录字幕生成 H.264/AAC 观看预览 MP4 | `ffmpeg`（libass/libx264/aac）；仅供预览，不替代专用游戏封装 |
| `delogo-preview` | 单一固定矩形+时段的简单去字预览（`--box X Y W H --start --end`） | `ffmpeg delogo`；仅适合纯色/平缓背景，禁止用于人物/动态复杂画面 |

统一字幕稿 schema 为 `localization-cues-v1`：保留稳定 `id`、整片秒数 `start`/`end`、`source`、`text` 与 `reviewed`（仅人工实际审校后改为 `true`）。

## 5. 硬字幕清底优先级

按顺序选择最小侵入路径：
1. 同版本无字幕片源或可拆软字幕轨；
2. 原游戏独立屏幕字幕层；
3. 简单平缓背景使用有依据的背景重建或 `delogo-preview` 验证；
4. 复杂动态背景按镜头切分制作逐帧遮罩，借助外部视频修复工具（如 ProPainter，需自行遵守其非商业许可并记录版本与参数）生成干净候选，经静帧与连续播放复查无残字/拖影后再烧入中文字幕，禁止用新字幕直接遮盖旧字残片。
