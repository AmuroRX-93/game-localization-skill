# PS2／PS3：PC、安卓与实机的交付选择

适用：制作或更新汉化发行包、为只有手机的玩家选择安装方式。核查日期：2026-09-28。下面是本项目推荐路线，不是所有游戏／设备已经通过的兼容承诺；实施时绑定游戏版本、模拟器／加载器版本和证据。

## 先分清三层

- **传输包装**：7z／ZIP，负责下载、分卷和归档；通常先解压。
- **运行内容**：PS2 光盘镜像、PS3 本体目录／专用 ISO／原生数字版安装内容；取决于宿主支持。
- **更新方式**：PS3 可用的更新 PKG，或在精确底座上合成新文件／镜像的差分。PKG 是安装容器，不等于二进制差分；不能把 .bsdiff/.xdelta 放进去就指望系统执行。

同一译文构建可以有多个平台出口，不强迫所有平台使用同一文件后缀。解压成功、PKG 安装成功、游戏加载汉化成功分别记录。

## 六种场景的默认路线

| 游戏／使用环境 | 本体怎样用 | 更新优先怎样交付 | 需要确认的边界 |
|---|---|---|---|
| PS2 · PC | 保留可校验的原始镜像为补丁基线；DVD 通常为 ISO，CD 保留实际轨道布局；宿主支持时可另转 CHD 等运行副本 | 校验底座的差分 → 新版镜像 → 模拟器重新打开 | 不直接把针对 ISO 的偏移补丁写入 CHD；特定模拟器支持 CHD 不代表实机支持 |
| PS2 · 安卓 | 解压后导入目标模拟器支持的 ISO／其他镜像 | 经验证支持该补丁算法和大文件的现成安卓修补器；否则在电脑合成后传入，或在有分发许可范围内提供完整新版内容 | 没有通用 PS2 更新 PKG；无电脑且无合适修补器时明确该路径未满足，不能假称 ZIP 复制即安装 |
| PS2 · PS2 实机 | 电脑／手机先解压和修补，再按具体 OPL 版本、USB／MX4SIO／SMB／HDD 等方式部署 | 合成新版镜像，再替换加载器管理的对应游戏；保留记忆卡／VMC | OPL 文件系统、介质和镜像格式逐项确认；HDD 安装方式可能不是简单复制 ISO；分卷 7z 不是可直接运行的分片镜像 |
| PS3 · PC | 优先保持可核查的本体目录；原生数字版使用匹配的安装内容；ISO 支持按宿主版本确认 | **经游戏加载验证的汉化更新 PKG**，用模拟器安装入口安装 | TITLE_ID、地区、官方更新和汉化底座匹配；本体／更新／DLC 读取优先级不能靠猜 |
| PS3 · 安卓 | 选择目标模拟器能配合更新 PKG 的本体形态，不为统一后缀强转本体 | **模拟器内安装同一份已验证适用的 PKG**；7z 用现成解压工具 | 查该版本是否支持“这种本体形态＋更新”；安装入口存在不等于内容加载成功；不要求玩家安装本项目自制安卓更新器 |
| PS3 · PS3 实机 | 以目标 CFW／HEN／加载器支持的 PS3 ISO 或目录部署；原生数字版另按实际条件 | **适配该环境的 PKG**，由 Package Manager 等安装入口处理 | CFW 与 HEN 分开验证；普通未改系统不默认支持自制包；模拟器接受的内容签名不等于实机接受 |

PS2 游戏在 PS3 上运行属于额外兼容路线，不由上述“PS2 实机”或“PS3 游戏”结论推导。

## PS3：PKG 是优先交付，不是无条件转换

1. 固定 TITLE_ID、地区、光盘／数字版本、官方更新版本、已有汉化版本和输入哈希。汉化发行号与 PARAM.SFO 中官方 APP_VER 分开记录，不能随意抬高 APP_VER 来绕过兼容检查。
2. 证明游戏实际读取安装目录中的目标资源。不能假设把光盘 USRDIR 里的任意文件放到更新目录就会覆盖；必要时适配可执行程序的资源路径，并记录依赖与回退。
3. 作者侧先生成最终完整资源，再按目标安装类型封装。更新所需 EBOOT、索引、归档及官方更新依赖一起核对；不将本体、DLC 和更新混为一包。某些游戏的更新可能依赖完整归档，因此 PKG 未必比差分小。
4. 区分包可解析、内容签名／格式可接受、正确安装、实际加载。具体 ISO／SELF／SDAT／EDAT 边界见 [PS3 封装与实机](ps3-packaging.md)。不是每个 PKG 都需要 RAP，也不因有 RAP 就认定所有签名问题已解决。
5. 首装包与累计更新写清最低底座。通用 PKG 安装入口不保证检查自定义汉化版本或旧文件哈希；先用作者侧校验和明确前置条件解决，不能宣称继承了差分安装器的全部防错能力。官方更新重装可能覆盖汉化，要说明安装顺序。
6. 卸载／回退按变更清单恢复，区分更新数据、DLC、安装数据和存档。不让玩家删除整个游戏数据目录来猜测修复，也不让升级包夹带个人存档。

目标游戏若不能通过更新路径覆盖，使用经验证的本体差分／重建方案，或者明确该平台暂不支持。**“优先 PKG”不等于把 PS2 或所有 PS3 光盘本体都改成数字版 PKG。**

## 7z、手机成本与大文件

- 本项目交付约定：超过 1 GB 的下载包装优先 7z；小型差分可继续 ZIP。这是分发偏好，不是运行格式要求。需直接安装的 PKG 可保留独立下载入口；若外层套 7z，说明先解压再安装，避免多层嵌套。
- 发布包附产品编号、版本、解压后入口、压缩包与关键输出 SHA-256、完整分卷名单、安装顺序及回退说明。7z 分卷齐全并合并解压之后，才按宿主需要另外制作分片镜像。
- 优先适中 LZMA2 参数；评估压缩收益后决定是否使用固实压缩和分卷。不要为了少量体积收益使用巨大字典或单一巨大固实块。解压内存受字典影响，固实块也影响单文件提取和损坏波及范围；不是文件越大就必然需要同等大小 RAM。
- 手机上的空间按实际流程估算：原下载包＋解压内容＋安装／转换临时输出＋需要保留的旧版。不要固定承诺“2倍就够”；流式解压也不能消除完整输出所需空间。验证后由玩家决定是否删除下载包。
- FAT32 单文件上限小于 4 GiB；分卷下载只能解决运输阶段的限制，不能让解压后的大 ISO／PKG 自动适配 FAT32。另选宿主明确支持的文件系统、网络安装／传输或专用分片方式。
- 安卓可用现成解压应用和系统文件选择器，按应用授权处理目录。不要默认可任意写入 Android/data 或模拟器私有目录。PS2／PS3 实机流程优先在电脑或手机解压，避免把主机端通用 7z 解包作为前提。

## 当前项目取舍与兼容边界

**本项目自制 Android 更新／转换原型已于 2026-09-28 退役**，不再作为玩家安装前置条件或后续维护方向。历史源码与测试只作记录；本 Skill 不携带或要求使用该 APK。其他用户已有工具仍按其明确需求处理，不把这个项目决定泛化为禁止所有安卓修补工具。

PC 的 Windows／macOS／Linux 与安卓分别列最低运行环境；若发行端要求 Windows 7，核查解压器、补丁器及依赖能否运行，不把这当成当前 PS3 模拟器也支持 Windows 7。操作系统向下兼容、低版本 Python、某台设备通过均不能替代实际依赖检查。iPhone 不在本项目当前范围。

每个平台标注“文档／源码依据、离线样例、安装、游戏运行”的实际证据。用户只要求理论方案时可以完成文档和静态检查，不为了补齐矩阵擅自启动游戏；未测格子保持未测。一次发布至少交代本体如何准备、更新如何装、进错版本如何辨认、存档如何保留。

以下来源用于选择路线，不是本项目已穷举验证的设备清单；发布具体补丁时复查相应版本。

- [RPCSX Android 安装入口](https://github.com/RPCSX/rpcsx-ui-android/blob/master/app/src/main/java/net/rpcsx/ui/navigation/AppNavHost.kt)：有 PKG 选择和安装流程，运行兼容另测。
- [aPS3e 官方 FAQ](https://github.com/aenu1/aps3e/wiki/FAQ-for-aPS3e_CN)：页面修订于 2025-07-26，2026-09-28 查阅仍写 PKG／目录游戏支持更新和 DLC，ISO 暂不支持；此为该文档时点的限制，不外推所有版本与模拟器。
- [PCSX2 CHD 读取实现](https://github.com/PCSX2/pcsx2/blob/master/pcsx2/CDVD/ChdFileReader.cpp)：支持运行压缩镜像不等于可以对压缩字节直接应用原始镜像补丁。

- [7z 格式](https://www.7-zip.org/7z.html)、[LZMA SDK](https://www.7-zip.org/sdk.html)：压缩方法、固实压缩和解压字典内存依据。
