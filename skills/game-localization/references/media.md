# 影音与字幕

## 载体和原文

区分原生事件字幕、实时引擎字幕、视频烧录文字、无字幕音轨和外部观看 MP4。导出观看合集与可回装影片是不同交付；片头四行地点标题汉化不等于整片对白汉化。

优先找游戏脚本原文与说话人／事件 ID，再核对原声。ASR 只是候选，姓名、番号、数字、否定和同音词结合上下文确认；多次机器识别一致不是人工听审。多声道要找准语音声道，识别不到不能直接断言无对白，也不能编台词。

每段记时长、帧数、音轨、对白判定、字幕来源、语言与时轴审校、排除依据。开发占位片即使不放观看合集，也留在总清单里。

## 原生字幕时序

检查文本、触发事件、窗口状态、显示区间、清屏、切镜、跳过与重播。文本在文件里不等于会显示。冷缓存编译卡顿和第二次平稳播放都检查；两遍漏不同句时调查触发时间窗，不要重复添加译文。

扩大时间窗须验证不重复、不重叠、不跨镜残留；帧率、跳帧和事件顺序可能影响显示。长句按语义与语音分段，倒计时依实际音频偏移核对。不能为了塞框无声删改对白。

## 影片回装

记录原容器、编码 profile／level、分辨率、timebase／帧率、帧数、GOP、音频编码与声道、时长、时间戳、码率峰值、流 ID、交织、索引、对齐和专用元数据。保留音轨时比有效载荷；封装字节变化不等于音频变化。

先用短代表片验证封装链：首帧、全片、跳过、结尾 loading、进入战斗、返回菜单。电脑播放器能解码不代表游戏解码器能处理。结构变化时检查解码队列和缓冲峰值；从最终游戏包重新提取检验。

黑屏用同一环境对照原片、未改字幕的重封装片和修改片。日志队列积压是现象，不能单凭它确定封装根因。

## 校验责任

不懂原语言的玩家可验证缺字、遮挡、显示／消失、声音和场景衔接；译义、说话人、细致对时需核对源材料。分开报告机器解码、语言复核、人工听审和游戏内观察。
