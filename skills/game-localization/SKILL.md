# 游戏汉化工程

把游戏汉化做成**可追溯、可回退、可验证**的工程。本 Skill 提供跨游戏的工程方法与基础工具，不提供万能解包器；具体平台、引擎、区域和版本仍需经验证的适配器。按本轮任务按需选用阶段，不为一个局部修正强行重跑全流程。

支持日译中、英译中以及日英混合资源；这表示工作流覆盖这些语言，不代表任意游戏格式已开箱即用。

## 1. 接手前先确认五件事

1. **基线身份**：从文件与记录确认游戏、平台、区域/产品编号、实际运行版本、原版指纹、现有补丁版本及运行入口；文件夹名、下载名与版本字段不能互相替代。
2. **语言与主译版本**：确认实际源语言（日文/英文/混合）、中文目标地区与主译版本；不把英文版默认当成日文直译，也不把说明文档语言当作游戏原文语言。
3. **本轮交付物**：明确是盘点清单、校对表、翻译草稿、可运行候选、回归修复、差分包还是正式发布。“小样”结合上下文判断是表格小样还是游戏内显示样例。
4. **范围与授权**：汉化、性能调优、控制逻辑改造与模拟器修复分开处理；研究请求不等于安装、删除或公开发布授权。若用户另有全局或工作区 `AGENTS.md` / 个人规则，优先遵循用户约定。
5. **真实加载路径**：本体、更新、DLC、安装数据、松散文件、归档副本的加载优先级可能不同；先证明目标文件实际被读取，再判断漏译，不盲删缓存。

## 2. 通用六步闭环

1. **固定基线，枚举资源**：保存指纹、资源路径及嵌套成员身份。未知容器、未识别区域与无法解码内容进入待查清单，不从分母里消失。先证明原样解包再封包不改变成员含义，再引入翻译。
2. **先做代表性小样**：选取短标签、长段落、动态变量、特殊符号及一种贴图/字幕路径，验证格式与技术可行性后再扩大；已有同版本成熟适配器和确认样式时可直接复用。
3. **翻译与工程分开留痕**：原文、现译、修订、上下文、术语依据与稳定 ID 分列。语义、字码、字形、排版分开校验；字显示错不一定是译文错。
4. **从基线生成候选**：用可重现脚本与修改清单从干净基线构建，不在多轮不明状态的产物上盲改。写回后重新抽取目标资源，核对修改白名单与未修改成员。
5. **按风险分层取证**：静态文本/字形检查、容器往返、实际加载、画面/声音/交互、内存高峰分别取证。全局字体或封包改动先过启动与高风险场景再推广；用户指定延后实测时照做并保留未验证状态。
6. **按证据交付**：明确区分“已生成/已写入/离线通过/已安装/已实测/已发布”，列出未测场景。发布包从同一确定构建生成，安装、旧版升级与还原说明与包内内容一致。

## 3. 核心工程红线

- **稳定身份**：以 `版本 + 容器链 + 成员/文本 ID + 上下文` 定位条目；同字符串不等于同语义，同文件名不等于同资源。
- **保护非翻译内容**：保护控制码、格式变量、内部资源键、路径分隔符、指针及空字符串边界；不把所有日文/英文都当可译文本。
- **统计口径分离**：不把假名清零、修改字节数或 OCR 数量当完成率；资源覆盖、条目覆盖、审校、字形映射与场景验证分开统计。
- **不跨版本套结论**：不凭同系列或同引擎直接套用格式结构、术语含义、补丁地址或崩溃原因，先核对当前版本证据。
- **字体与内存克制**：优先统一字体源与语义码表，兼容字形尽量复用；按消费者收集所需字符，避免给固定标题/数字字库灌入全字集，扩字前先预算驻留内存。
- **UI 贴图重绘**：UI 汉化采用底图/装饰重建加独立中文排字，**禁止在原字上盖纯色块或透明洞再叠字**；保留原边框、渐变、高光、图标与真实显示锚点。
- **保护基线与存档**：保留用户存档与当前可玩版本；实验副本不得通过硬链接或共享路径污染原版基线。
- **版权与隐私边界**：保留原译文、素材、字体与工具的来源及许可记录；公开仓库与发布包不夹带个人存档、密钥、BIOS、聊天记录或未授权资产。

## 4. 工具入口

核心脚本位于本 Skill 目录下的 `scripts/`（技能目录视为只读源，所有输出写入任务工作区），详情与支持边界见 [工具包与清单手册](references/toolkit.md)：

- `python3 scripts/localization_toolkit.py doctor`：检查 Python 与可选依赖。
- `python3 scripts/toolkit_selftest.py`：用虚构样本验证抽取、回填、容器往返与差分流程。
- `python3 scripts/audit_ledger.py <ledger.json>`：离线检查项目清单中的遗漏与状态矛盾。
- `python3 scripts/media_toolkit.py doctor`：可选影音转写与字幕预览工具诊断。

所有工具写入均生成新候选、拒绝覆盖输入，不自动安装到游戏或启动模拟器。
